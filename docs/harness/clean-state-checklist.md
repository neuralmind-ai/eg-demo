# Clean state checklist

Adapted from WalkingLab's starter template. Use before every handoff.

- [x] Standard startup ./init.sh passed.
- [x] Host and connected Android verification paths passed locally.
- [x] Progress log contains commands and outcomes.
- [x] Feature ledger separates verified foundation from future work.
- [x] Handoff records limitations and next feature.
- [x] SDKs, caches, local paths, generated APKs, and runtime evidence are ignored.
- [x] Wrapper, schema, app source, instructions, and CI are included in the checkpoint.

This records the foundation session; later sessions should refresh these checks
against their actual evidence. Git checkpoint completion is recorded in the final
response and visible in git history.
